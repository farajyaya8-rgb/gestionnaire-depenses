# Gestionnaire de dépenses

Application console en Python pour suivre ses dépenses.

## Fonctionnalités
- Ajouter, afficher, modifier, supprimer une dépense
- Recherche par description
- Total général, par catégorie et du mois
- Sauvegarde dans un fichier JSON

## Lancer le projet
python main.py

## Ce que j'ai appris
Fonctions, dictionnaires, fichiers JSON, validation des saisies, Git.
